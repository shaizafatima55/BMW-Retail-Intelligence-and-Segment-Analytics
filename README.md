# BMW Retail Intelligence & Segment Analytics

## 📌 Project Overview
This repository showcases an end-to-end Business Intelligence solution engineered using **Power BI Desktop**. The project transforms complex, multi-dimensional automotive data into an executive-ready analytics suite. 

The primary objective is to monitor high-level sales KPIs and deliver deep product-segment insights, allowing stakeholders to understand which vehicle configurations (fuel, transmission, body style) drive the highest revenue.

## 🛠️ Technical Stack & Architecture
* **BI Platform:** Power BI Desktop
* **Data Modeling:** Star Schema (Dimensional Modeling linking sales facts with product & specification dimensions)
* **ETL Pipeline:** Power Query (M Language) for data cleansing, formatting, and structural integrity
* **Analytical Engine:** Advanced DAX (Data Analysis Expressions) for dynamic performance metrics

## 🚀 Dashboard Insights & Features
* **Executive Performance Tracking:** Instant visibility into core business health via high-level metrics: **Total Revenue, Total Units Sold, and Average Vehicle Price**.
* **Model Hierarchy Ranking:** Interactive ranking matrix isolating top-performing BMW models (X5, iX, M5, etc.) by volume and financial contribution.
* **Granular Segment Analytics:** Multi-dimensional cross-filtering that breaks down sales performance across:
  * **Fuel Type:** Electric, Hybrid, Petrol, Diesel.
  * **Mechanical Specs:** Transmission (Automatic vs. Manual) and Engine Capacity.
  * **Design & Aesthetics:** Consumer demand tracking based on Body Type (SUV, Sedan, Coupe).
* **UI/UX Engineering:** Modern canvas layout featuring sleek visual hierarchies, custom tooltips, and seamless slicer navigations.
